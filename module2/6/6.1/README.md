
## Реализация статической библиотеки

Исходный код библиотеки находится в файлах `src/contacts.c` и `src/contacts.h`. Сборка автоматизирована через `Makefile` и проходит в два этапа:
1. Компиляция исходника `contacts.c` в объектный бинарный файл `obj/contacts.o`.
2. Упаковка архива с помощью утилиты `ar`:
   ```bash
   ar rcs lib/libcontacts.a obj/contacts.o
   ```

### Подключение к модулям проекта
Для использования функций двусвязного списка основное приложение (`main.c`, `menu.c`) и юнит-тесты (`test.c`) используют заголовочный файл:
```c
#include "contacts.h"
```
На этапе сборки линковка выполняется с помощью флагов поиска путей и имени библиотеки: `-Llib -lcontacts`.

---

### Тест на автономность
Так как при статической линковке весь скомпилированный код функций списка копируется непосредственно внутрь вашей программы, исполняемый файл становится абсолютно независимым от файлов сборки.

1. Полностью соберите проект:
   ```bash
   make
   ```
2. Удалите папку с собранной статической библиотекой:
   ```bash
   rm -rf lib/
   ```
3. Запустите приложение или юнит-тесты напрямую:
   ```bash
   ./bin/phonebook
   # или
   ./bin/unit_tests
   ```

Результат: Программа успешно запустится и будет выполнять все свои функции, несмотря на то, что файла библиотеки `libcontacts.a` на диске больше нет.



### Описание юнит-тестов

В проекте реализовано автоматическое тестирование основных функций статической библиотеки с использованием фреймворка Unity:

* `test_AddContact_ShouldSortByLastName` — Проверяет вставку контактов и корректность автоматической сортировки по фамилии (`lastName`) в алфавитном порядке, а также правильность установки связей `next` и `prev` между узлами.
* `test_DelContact_ShouldDeleteCorrectly` — Тестирует последовательное удаление элементов из разных позиций списка: из середины, из начала (обновление корня `root`), и удаление последнего оставшегося элемента.
* `test_EditContact_ShouldResortWhenLastNameChanges` — Проверяет динамическую пересортировку: при изменении фамилии узел извлекается и перемещается в правильную по алфавиту позицию (в данном случае — в начало списка).
* `test_AddContact_ShouldReturnErrorOnNullPointer` — Проверяет устойчивость функции к ошибкам: при передаче некорректного указателя (`NULL` вместо адреса списка) функция должна вернуть код ошибки `-1`.
