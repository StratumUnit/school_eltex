# Калькулятор с динамической загрузкой операций

Программа калькулятор на языке C, в котором математические операции реализованы в виде отдельных динамических библиотек (.so). Основное приложение не содержит жестко прописанного списка операций. Вместо этого при старте оно сканирует указанную директорию, находит доступные библиотеки и загружает их функции в память с помощью dlfcn.h


## Структура проекта

* src/ — папка с исходным кодом. Содержит main.c (основной цикл калькулятора) и исходные файлы операций (add.c, substraction.c и т.д.).
* libs/ — папка, в которую компилируются готовые динамические библиотеки (создается автоматически).	
* bin/ - каталог с основным исполняемым файлов
* Makefile — скрипт автоматической сборки.

 ## Взаимодействие между основным приложением и библиотеками
В коде определена общая структура:


```c
typedef  struct  {
const  char  *name;
double (*func)(double, double);
} FuncInfo;
```

Каждый плагин в папке src/ должен содержать функцию с именем getInfo, которая возвращает эту структуру. Через нее библиотека передает основному приложению название операции для отображения в меню и указатель на свою математическую функцию.
```c
FuncInfo  getInfo(void)
{
FuncInfo  info  = {"Add", opSum};
return  info;
}
```

Основная программа сканирует папку libs/, для каждого файла вызывает dlopen() и через dlsym() запрашивает символ "getInfo". Если функция найдена, в массив структур операций записывается указатель на неё. При выходе из программы все открытые дескрипторы закрываются через dlclose().


## Работа сборки Makefile

Сборка проекта полностью автоматизирована и адаптируется под изменения в коде:

Динамический поиск плагинов: Makefile автоматически сканирует каталог `src/` на наличие исходных файлов. С помощью функции `filter-out` он исключает файл `main.c` из общего списка, оставляя только файлы математических операций.
```makefile
PLUGIN_SRCS := $(filter-out $(SRC_DIR)/main.c, $(wildcard $(SRC_DIR)/*.c))
```
Для сборки плагинов используется универсальное правило. Компилятор преобразует каждый найденный файл операции в отдельную библиотеку с префиксом `lib` и расширением `.so` в папку `libs/`.
```makefile
LIBS := $(patsubst $(SRC_DIR)/%.c, $(LIB_DIR)/lib%.so, $(PLUGIN_SRCS))
```
При сборке плагинов используются обязательные флаги `-fPIC` (для генерации позиционно-независимого кода) и `-shared` (для сборки разделяемой библиотеки).
```makefile
$(LIB_DIR)/lib%.so: $(SRC_DIR)/%.c
@mkdir -p $(LIB_DIR)
gcc $(CFLAGS) -fPIC -shared -o $@  $< -lm
```
При сборке основного приложения подключаются системные библиотеки `-ldl` (для работы механизмов `dlopen`/`dlsym`) и `-lm` (для корректной работы математических макросов, таких как `isnan`).
```makefile
$(TARGET): $(SRC_DIR)/main.c
@mkdir -p $(BIN_DIR)
gcc $(CFLAGS)  $< -o $@ -ldl -lm
```
